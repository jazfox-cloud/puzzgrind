# TASK-007 — Playable Sudoku UI

## Goal

Deliver a mobile-first playable Daily Sudoku using the TASK-006 API.

## Acceptance

- The homepage links to `/sudoku`.
- Givens are immutable and visually distinct.
- Pointer and keyboard input work.
- Notes, erase, undo, redo, timer, pause, and conflict feedback work.
- Focus and selection are visible and feedback does not rely on color alone.
- A complete valid board locks input and shows completion feedback.
