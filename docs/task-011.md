# TASK-011 — Result, share, and polished game feedback

## Goal

Turn a verified completion into a clear, trustworthy result experience with privacy-safe sharing and the next UTC challenge countdown.

## Acceptance

- Results show server-verified time, mistakes, hint count, maximum hint level, and no-hint status.
- Samples below 20 never show misleading averages or percentages.
- Web Share is preferred with clipboard fallback and no anonymous ID.
- The share text contains no answer or board state.
- The next UTC challenge countdown is visible.
- Completing or refreshing a won session keeps input locked without duplicate submission.
